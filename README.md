# Student Grade Report

Python script that prints a class report from a hardcoded list of students and three scores each.

It calculates each student's total, average, and letter grade, then prints the class average, how many students scored above that average, and the topper.

## Run

```bash
python messy.py
```

Requires Python 3. No extra packages.

## What it prints

- `REPORT`
- One line per student: name, total, average, grade (`A`–`F`)
- Class average
- Count of students strictly above the class average
- Topper name and average

Sample output is in `original_output.txt`. Screenshots of earlier runs are in `Output.png` and `Final_Output.png`.
